# Horario y tareas · 2º DAM

App web instalable (PWA) con el horario de clases y un gestor de entregas. Funciona sin conexión.

- Las tareas se guardan **solo en tu dispositivo** (en el navegador); no se envían a ningún servidor.
- Puedes importar el calendario de Moodle (`.ics`) y exportar/importar una copia de tus tareas.
- Código de la página: `index.html` (un solo archivo, sin dependencias).
